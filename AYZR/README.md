# AYZR — منصة ذكاء وتحليل الذهب (XAUUSD)

منصة تحليل ذهب مستقلة تعمل على بيانات **BiQuote** الحقيقية. تعرض الشارت، مناطق
العرض والطلب والسيولة، الإشارات، والصفقات الافتراضية — **بدون أي تنفيذ تداول حقيقي**.

> **وضع الظل فقط (SHADOW ONLY).** المنصة لا تُرسل أوامر ولا تتصل بحساب تداول.
> كل «الصفقات» افتراضية وتُحسب لأغراض قياس أداء المحركات فقط.

## التشغيل

```bash
# 1) الواجهة الخلفية (تجلب بيانات BiQuote الحقيقية)
cd server
npm install
AYZR_OPERATOR_TOKEN=ayzr-operator-demo PORT=12000 npm start

# 2) الواجهة الأمامية — تُبنى مرة واحدة وتُقدَّم من الخادم نفسه
cd ../web
npm install
npm run build
```

ثم افتح: `http://localhost:12000`

الواجهة تُقدَّم من نفس الخادم (`server/src/index.mjs` يخدم `web/dist`)، فلا حاجة
لتشغيل خادم منفصل للواجهة.

### الاختبارات

```bash
cd server && npm test
```

## الإعدادات (متغيرات البيئة)

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `PORT` | `8787` | منفذ الخادم |
| `AYZR_OPERATOR_TOKEN` | فارغ | رمز المشغل. بدونه تبقى أدوات التحكم والذكاء الاصطناعي مقفلة |
| `AYZR_POLL_MS` | `15000` | دورة تحديث البيانات |
| `AYZR_BARS` | `400` | عدد الشموع لكل إطار |
| `AYZR_DERIVED_SOURCE_BARS` | `730` | شموع D1 المستخدمة لتجميع W1 و MN1 |
| `AYZR_DB` | `data/ayzr.sqlite` | مسار قاعدة البيانات |
| `AYZR_AI_PROVIDER` | `none` | مزوّد الذكاء الاصطناعي. `none` يعني «غير متاح» بصراحة |
| `AYZR_AI_API_KEY` | فارغ | مفتاح المزوّد |

## المحركات

ستة محركات مستقلة، كل واحد يعلن مدخلاته ومخرجاته وحدوده وسبب عدم إصداره:

| المحرك | ما يكشفه |
|---|---|
| `liquidity` | تجمعات السيولة أعلى القمم المتساوية / أسفل القيعان المتساوية، وكنس السيولة |
| `levels` | الدعم والمقاومة من نقاط التلامس المتعددة |
| `supplyDemand` | مناطق العرض والطلب (قاعدة ثم اندفاع) |
| `structure` | كسر البنية (BOS) وتغير الطابع (CHoCH) |
| `imbalance` | فجوات القيمة (FVG) وأوردر بلوك |
| `breakout` | الاختراق المؤكد والاختراق الكاذب |

### دورة حياة المنطقة

`DISCOVERED → WAITING_APPROACH → APPROACH → UNDER_VALIDATION → CONFIRMED_RETEST | CONFIRMED_BREAKOUT | FAKE_BREAKOUT | EXPIRED`

لا تُنشر إشارة إلا عند حالة مؤكدة. المنطقة المستهلكة تنتهي (`EXPIRED`) بدل أن تُؤكد إلى الأبد.

## الالتزامات

- **لا تنفيذ حقيقي.** لا يوجد أي مسار لإرسال أوامر في الخادم (مُختبَر).
- **لا اختلاق.** عند نقص البيانات تُعلن المحركات `INSUFFICIENT_HISTORY` مع السبب،
  وعند غياب مزوّد الذكاء الاصطناعي يُعاد `NOT_AVAILABLE` بصراحة.
- **الدرجات ليست احتمالات.** كل درجة هي ترتيب داخلي غير مُعاير، ويُذكر ذلك في الواجهة.
- **التكاليف محتسبة.** كل صفقة افتراضية تحمل السبريد والانزلاق في نتائجها.
- **الشفافية.** «حسب المحرك» يعرض `—` لا صفراً عندما لا توجد بيانات كافية.
- **لا نظرة مستقبلية.** لا تُقيَّم صفقة على شموع أُغلقت قبل إنشائها (اختبار انحدار).

## مصدر البيانات

كل الأسعار والشموع من BiQuote مباشرة. الأطر `W1` و `MN1` مُجمّعة من شموع `D1`
القادمة من المصدر نفسه، وتُعلَّم بـ `*` في الواجهة. راجع
`server/docs/BIQUOTE_DISCOVERY.md` لتقرير الاستكشاف الفعلي.
