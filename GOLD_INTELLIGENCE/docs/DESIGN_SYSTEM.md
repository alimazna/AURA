## 1. فلسفة التصميم

الواجهة يجب أن تبدو **منصة ذكاء مالي دولية متميّزة**، لا قالب عام.

| الأولوية | التطبيق |
|---|---|
| مهنية وموثوقة | كثافة معلومات منظمة، تباين عالٍ، بلا زخرفة |
| صديقة للمبتدئين | مصطلحات مشروحة سياقيًا، وسم واضح للحالة |
| تسلسل هرمي واضح | السيناريو الحالي أولًا، التفاصيل عند التوسيع |
| مخططات مالية عالية الجودة | شارت الشموع هو العنصر البصري الأول |
| طباعة مقروءة | أحجام عربية واضحة (≥11px) |
| سرعة التحميل | بلا رسوم متحركة زائدة |
| استجابة كاملة | Desktop / Laptop / Tablet / Mobile |

**ما يجب تجنّبه:** الرسوم المتحركة الزخرفية، التعقيد البصري بلا وظيفة، نسخ أرقام الصورة
التجريبية، الاعتماد على اللون وحده (يجب أن يرافقه نص/رمز).

## 3. نظام الطباعة (Typography)

### 3.1 السلّم

| Token | القيمة | الاستخدام |
|---|---|---|
| `--t-micro` | 11px | **الحد الأدنى المطلق** (العربية غير مقروءة أقل منه) |
| `--t-small` | 11.5px | تسميات |
| `--t-body` | 13px | النص الأساسي |
| `--t-lead` | 14px | نص بارز |
| `--t-title` | 15px | عناوين الأقسام |
| `--t-display` | 26px | الأرقام الكبيرة (السعر) |

### 3.2 الخطوط

| النوع | العائلة |
|---|---|
| عربي (Sans) | `IBM Plex Sans Arabic` → `Segoe UI` → `system-ui` |
| Monospace (أرقام) | `JetBrains Mono` → `ui-monospace` |

**قواعد العربية:**
- `letter-spacing: 0` دائمًا (التتبع يكسر أشكال الوصل).
- `line-height: 1.6` للجسم (أعلى من اللاتينية).
- الأرقام في عمود Monospace مع `font-variant-numeric: tabular-nums` لعدم اهتزازها.

## 5. مبادئ التخطيط

- **Grid أساسي:** 12 عمودًا على Desktop، ينهار إلى عمود واحد على Mobile.
- **المنطقة الوسطى (Chart) هي البطل** في الشاشة الرئيسية و«Ready Trades».
- **لوحة السيناريو** على الجانب (يمين في RTL).
- **الشريط السفلي:** بطاقات (مناطق/إشارات/أداء/جودة بيانات).
- **لا تمرير أفقي** على أي شاشة.

## 6. الحالات الدلالية للسيناريو (Status Tokens)

كل حالة سيناريو لها: لون + رمز + نص. **لا يُستخدم اللون وحده أبدًا.**

| الحالة | اللون | الرمز | النص العربي |
|---|---|---|---|
| `PUBLISHED` | `--cyan` | ● | منشور |
| `WAITING_FOR_ACTIVATION` | `--warn` | ◐ | بانتظار التفعيل |
| `ACTIVATED` | `--blue` | ▶ | مفعّل |
| `PARTIALLY_COMPLETED` | `--up` (خافت) | ◑ | مكتمل جزئيًا |
| `TARGET_REACHED` | `--up` | ✓ | تحقق الهدف |
| `STOP_LOSS_REACHED` | `--down` | ✕ | تحقق وقف الخسارة |
| `CANCELLED` | `--fg-dim` | ⊘ | ملغى |
| `EXPIRED` | `--fg-dim` | ⏱ | منتهي الصلاحية |
| `INVALIDATED` | `--down` (خافت) | ⊗ | مُبطل |
| `NOT_ACTIVATED` | `--fg-faint` | ◌ | لم يُفعَّل |

## 9. قواعد إمكانية الوصول (WCAG 2.1 AA)

1. تباين نص الجسم ≥ 4.5:1 على خلفيته.
2. **لا نص عربي أصغر من 11px.**
3. لا تعتمد دلالة على اللون وحده (لون + رمز + نص).
4. أهداف اللمس ≥ 44×44px على Mobile.
5. تركيز لوحة المفاتيح مرئي على كل عنصر تفاعلي.
6. `prefers-reduced-motion` مُحترم (إيقاف الحركات غير الضرورية).
7. لغة الصفحة `lang="ar"` و`dir="rtl"`، مع `dir="ltr"` للأرقام والرموز اللاتينية.

## 10. نظام الحركة (Motion)

| الاستخدام | المسموح | الممنوع |
|---|---|---|
| تغيّر السعر | نبضة خفيفة (200ms) | حركات مستمرة |
| ظهور بطاقة | Fade 150ms | Slide/Bounce |
| تحديث الحالة | Cross-fade | Spin/Shake |
| شارت | بلا حركة | Animated redraw |

**القاعدة:** الحركة تُخدم الفهم فقط، لا الزخرفة.
