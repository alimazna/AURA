# USER_FLOWS.md — تدفقات المستخدم

> **المستند 5 من 17** | الحالة: مسودة PHASE 3 | آخر تحديث: 2026-11-14

## 1. الشخصيات (Personas)

| الشخصية | الوصف | الحاجة الأساسية |
|---|---|---|
| **المبتدئ** (أحمد) | أول تجربة له مع الذهب | «افهم ما أراه ولماذا، بلا مصطلحات مربكة» |
| **المتداول المتوسط** (سارة) | 1–3 سنوات خبرة | «فرص مُدلَّلة + سجل صادق لأثق بالمنصة» |
| **المحترف** (خالد) | يريد عمقًا | «بنية سوق، أدلة، إحصاءات، نسخة القواعد» |
| **المشكّك** (منى) | يجرّب المنصة | «أرى الخسائر أيضًا، لا الرابحة فقط» |

## 2. التدفق الرئيسي: من الزيارة إلى متابعة سيناريو

```
1. زيارة
   │
   ▼
2. Home — نظرة سريعة (سعر، حالة بيانات، أحدث السيناريوهات)
   │
   ▼
3. Ready Trades — الفرص الحالية
   │
   ├─ [لا فرصة] ──► «لا توجد فرصة صالحة» + السبب + سياق
   │                      │
   │                      └─► [لماذا؟] ──► شرح منهجية القرار
   │
   └─ [فرصة موجودة]
          │
          ▼
4. بطاقة السيناريو (حالة واضحة: بانتظار التفعيل / مفعّل)
          │
          ├─► [💡 لماذا هذا السيناريو؟]
          │        │
          │        ├─► شرح مبسّط (افتراضي) — لغة يومية
          │        └─► [تحليل احترافي ▸] — بنية، أدلة، مستويات
          │
          └─► [متابعة (محاكاة)]
                   │
                   ├─ (أول مرة) ──► RiskBanner إلزامي
                   │                   │
                   │                   └─► إقرار ──► تسجيل risk_ack_at
                   │
                   ▼
5. تسجيل المتابعة (scenario_follows)
          │
          ▼
6. My Previous Trades — متابعة النتيجة لاحقًا
```

## 3. التدفق: المبتدئ يتعلّم داخل السياق

```
مستخدم يرى مصطلح «وقف الخسارة»
   │
   ▼
تلميح سياقي (tooltip/inline) — «وقف الخسارة: السعر الذي تُغلق عنده الصفقة لتحديد
أقصى خسارة. في هذا السيناريو: 4031.50، أي أقل من الدخول بـ 12.00 نقطة.»
   │
   ▼
[لماذا يهمني هذا؟] ──► بطاقة تعليمية قصيرة + مثال مرئي على الشارت
   │
   ▼
العودة للسياق بلا فقدان الموقع
```

**قاعدة:** لا يُطلب من المستخدم مغادرة الصفحة للتعلم.

## 4. التدفق: المشكّك يفحص السجل

```
Education & Performance
   │
   ▼
جدول الأداء (مع التعاريف أعلى الجدول)
   │
   ├─► «إجمالي المنشور: 120 | المفعّل: 54 | غير المفعّل: 41 | ملغى: 12 | منتهي: 13»
   ├─► «رابح: 31 من 54 مفعّل = 57.4%» ← المقام معلن
   │
   ▼
[كيف نحسب هذا؟] ──► صفحة المنهجية (تعريف المقام، التكاليف، الافتراض المتحفظ)
   │
   ▼
فلترة بالفترة/الفئة ──► إحصاءات محدثة
   │
   ▼
الوصول إلى أي سيناريو خاسر لرؤية سبب الخسارة
```

## 5. التدفق: المستخدم يسأل المساعد

```
Gold AI Assistant
   │
   ▼
سؤال: «لماذا لا توجد فرصة اليوم؟»
   │
   ▼
المساعد يجلب: آخر لقطة سياق + آخر تقييم محرك + سجل no_opportunity
   │
   ▼
إجابة + مراجع مرئية:
   «لا توجد فرصة صالحة لأن [السبب]. [المرجع: لقطة السياق 2026-11-14 14:00 UTC]»
   │
   ▼
وسم: «تفسير مُولَّد — البيانات الأساسية موثقة»
```

**حالة الفشل:** إن لم يجد المساعد بيانات كافية → «لا تتوفر بيانات كافية للإجابة حاليًا».

## 6. التدفق: بيانات قديمة/مفقودة

```
أي شاشة تعرض سعرًا
   │
   ▼
FreshnessBar يفحص عمر آخر تحديث
   │
   ├─ [FRESH] ──► عرض طبيعي
   ├─ [AGING] ──► شريط أصفر «آخر تحديث قبل X دقيقة»
   ├─ [STALE] ──► شريط تحذير + تعطيل أزرار المتابعة
   └─ [INTERRUPTED] ──► «البيانات غير متاحة» + لا شارت كاذب + لا تأكيدات
```

**قاعدة:** لا يُعرض سعر بلا عمر محدّث. لا يُسمح بتأكيد جديد أثناء الانقطاع.

## 7. التدفق: حدث اقتصادي

```
شريط «حدث اقتصادي وشيك: قرار الفائدة — بعد 45 دقيقة»
   │
   ▼
[التفاصيل] ──► Event Detail: الوقت، الأهمية، المتوقع، السابق
   │
   ▼
بعد الحدث ──► Event Reaction Record: التفاعل الفعلي (PILLAR 5)
   │
   ▼
«السعر تحرك X نقطة في Y دقيقة» ← بيانات موثقة، لا تفسير سببي مُفترض
```

## 8. تدفق تشغيلي: المشغل (Operator)

```
Operator Console (محمي بـ token)
   │
   ├─► مراجعة مرشّحات المحرك
   ├─► [نشر] ──► يتطلب اجتياز Quality Gate + تسجيل Audit
   ├─► [إلغاء] ──► يتطلب سببًا إلزاميًا
   └─► [تفعيل إصدار قواعد جديد]
```

**قاعدة:** لا فعل تشغيلي بلا سبب مسجّل، ولا بلا Audit entry.

## 9. تدفق: انتهاء سيناريو

```
سيناريو مفعّل
   │
   ├─► تحقق TP ──► TARGET_REACHED ──► outcome (Append-only)
   ├─► تحقق SL ──► STOP_LOSS_REACHED ──► outcome
   ├─► تحقق إبطال ──► INVALIDATED ──► outcome
   └─► انتهاء الأفق ──► EXPIRED ──► outcome
            │
            ▼
   تحديث السجل العام فورًا (لا تأخير في إظهار الخسارة)
            │
            ▼
   إشعار المستخدمين الذين تابعوا (إن مُفعّل)
```

**قاعدة حرجة:** **لا يُحذف** السيناريو الخاسر، ولا يُخفى من السجل، ولا يُؤجَّل تحديثه.

## 10. مخطط الحالات الذهنية للمستخدم (Mental Model)

المنتج يجب أن يُرسّخ ثلاثة أفكار:

1. **«سيناريو منشور ≠ فرصة مفعّلة»** — التمييز مرئي في كل مكان.
2. **«الدرجة ليست احتمالًا»** — مكتوب حيث تظهر الدرجة.
3. **«قد لا توجد فرصة، وهذا جيد»** — رسالة صادقة، لا محتوى مُصطنع.
