# ACCEPTANCE_CRITERIA.md — معايير القبول

> **المستند 15 من 17** | الحالة: مسودة | آخر تحديث: 2026-11-14
> **قاعدة:** لا يُعلن أي بند مكتملًا بلا دليل مُنفَّذ فعليًا. لا نتائج اختبار مُختلقة.

## 1. معايير المنتج العامة (Product-level)

| # | المعيار | طريقة التحقق |
|---|---|---|
| AC-01 | المنتج يعمل على XAUUSD فقط | محاولة إضافة أداة أخرى → مرفوضة |
| AC-02 | لا يوجد أي مسار تنفيذ حقيقي | مراجعة الكود + اختبار عدم وجود endpoint تنفيذ |
| AC-03 | كل رقم معروض له مصدر وتوقيت | فحص كل عنصر واجهة + اختبار API |
| AC-04 | النظام يُعلن «لا توجد فرصة» بنجاح | اختبار وحدة + اختبار تكامل |
| AC-05 | الدرجة مُوسمة صراحة كغير مُعايرة | فحص الواجهة + النصوص |
| AC-06 | البيانات الناقصة تُعرض «غير متاح» | محاكاة نقص بيانات → لا قيمة مُخترعة |
| AC-07 | السجل يشمل الخاسر والملغى والمنتهي وغير المفعّل | استعلام سجل + فحص عرض |
| AC-08 | لا حذف لأي سيناريو | محاولة حذف → مرفوضة/أرشفة فقط |
| AC-09 | كل التوقيتات UTC في DB وتُعرض محليًا | فحص schema + فحص عرض |
| AC-10 | تحذير المخاطر يظهر قبل أول متابعة | اختبار تدفق مستخدم جديد |

## 2. معايير طبقة البيانات

| # | المعيار | طريقة التحقق |
|---|---|---|
| AC-D01 | 100% من الشموع تحمل `source_id`+`fetched_at` | استعلام: `COUNT(*) WHERE source_id IS NULL` = 0 |
| AC-D02 | الشمعة غير المكتملة لا تُستخدم في قرار | اختبار: لا انتقال حالة بشمعة `is_closed=false` |
| AC-D03 | OHLC غير المنطقي يُرفض | اختبار: High < Low → `INVALID_OHLC` |
| AC-D04 | الفجوات تُكتشف وتُسجَّل | اختبار فجوة مُصطنعة → `GAP_DETECTED` |
| AC-D05 | التكرار يُمنع | إدراج شمعتين بنفس المفتاح → واحدة فقط |
| AC-D06 | البيانات القديمة تُوسم `STALE` وتُعطّل التأكيد | اختبار: شمعة قديمة → لا تفعيل |
| AC-D07 | تعارض المصادر يُكتشف ويُوقف النشر | محاكاة اختلاف فوق العتبة → `DATA_CONFLICT` |
| AC-D08 | انقطاع المزوّد لا يُنتج تأكيدًا | محاكاة فشل → لا انتقالات جديدة |
| AC-D09 | Repaint يُسجَّل ولا يُعدّل النتيجة | تغيير شمعة تاريخية → `candle_revisions` فقط |
| AC-D10 | التحويل للاحتياطي يعمل | محاكاة فشل الأساسي → الاحتياطي يخدم |

## 3. معايير آلة الحالة

| # | المعيار | طريقة التحقق |
|---|---|---|
| AC-L01 | كل انتقال مسجّل بسبب+وقت+بيانات | فحص `scenario_status_history` |
| AC-L02 | لا انتقال عكسي من حالة نهائية | اختبار: محاولة رجوع → مرفوضة |
| AC-L03 | Idempotency يعمل | إعادة نفس الانتقال → لا تكرار |
| AC-L04 | EC-1: حركة في الاتجاه قبل التفعيل ≠ نجاح | اختبار السيناريو الكامل |
| AC-L05 | EC-3/EC-4: SL و TP بنفس الشمعة → SL أولًا | اختبار |
| AC-L06 | EC-5: انقطاع → تجميد معلن بلا تأكيد | اختبار |
| AC-L07 | EC-12: انتهاء داخل منطقة الدخول → `EXPIRED` لا `NOT_ACTIVATED` | اختبار |
| AC-L08 | EC-13: تعارض تفعيل/إبطال → الإبطال | اختبار |
| AC-L09 | EC-15 حالة حدّية إضافية | اختبار |
| AC-L10 | R/R محسوب لا مُدخل يدويًا | محاولة إدخال → يُتجاهل/يُرفض |
