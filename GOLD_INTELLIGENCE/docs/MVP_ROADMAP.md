## 1. نطاق MVP

### داخل MVP

1. Ready-to-Follow Trades Center ⭐
2. Scenario Generation Engine
3. AI Explanation لكل سيناريو
4. Shadow Scenario Monitoring
5. Transparent Historical Results Ledger
6. Gold Daily Brief
7. Beginner Education Mode
8. Personal Gold AI Assistant

Advanced Replay Lab · Advanced Event Research · Personal Performance Coach ·
Advanced Statistical Studies · أدوات احترافية إضافية.

## 2. المراحل والمعالم

### M0 — التأسيس (Foundation)

| البند | التفصيل |
|---|---|
| **الأهداف** | مستودع، بيئة، CI، أسرار، هيكل خدمات |
| **المكونات** | Repo، Docker Compose، DB schema v1، Redis، CI |
| **المهام** | إنشاء المستودع؛ هيكل الخدمات؛ migrations أولية؛ CI (lint/test/build)؛ إدارة أسرار |
| **الاعتماديات** | موافقة المعمارية (PHASE 4) |
| **المخرجات** | بيئة تعمل محليًا + CI أخضر |
| **الاختبارات** | اختبار بناء، اختبار migrations، اختبار اتصال DB |
| **معايير القبول** | `docker compose up` ينجح؛ CI يمر على commit نظيف |
| **المخاطر** | تعقيد مبكر زائد — التخفيف: Monolith بسيط |

### M1 — طبقة البيانات (Market Data)

| البند | التفصيل |
|---|---|
| **الأهداف** | جلب وتحقّق بيانات XAUUSD حقيقية |
| **المكونات** | Ingestion، Validation، Adapter للمزوّدين، Freshness |
| **المهام** | Adapter أساسي؛ Adapter احتياطي؛ فحوص التحقق التسعة؛ Freshness state؛ Rate limiting؛ Circuit breaker |
| **الاعتماديات** | **DECISION D (المزوّد) + مفاتيح API** |
| **المخرجات** | شموع XAUUSD صحيحة مخزّنة بوسم المصدر |
| **الاختبارات** | دقة OHLC؛ الفجوات؛ الشمعة غير المكتملة؛ التكرار؛ القديم؛ تعارض المصادر؛ انقطاع المزوّد |
| **معايير القبول** | 100% من الشموع المخزّنة تحمل `source_id`+`fetched_at`؛ لا شمعة `is_closed=false` تُستخدم في قرار |
| **المخاطر** | جودة المزوّد غير كافية — التخفيف: مزوّد احتياطي |

### M2 — النواة الحتمية (Deterministic Core)

| البند | التفصيل |
|---|---|
| **الأهداف** | سياق السوق + آلة الحالة + حساب R/R |
| **المكونات** | Context Engine، Lifecycle Machine، Risk/RR، Evidence Store |
| **المهام** | بنية/اتجاه/تقلب/نظام؛ آلة الحالة بكل الحالات؛ Idempotency؛ الافتراض المتحفظ؛ Evidence CRUD |
| **الاعتماديات** | M1 |
| **المخرجات** | محرك ينتج لقطة سياق + ينتقل الحالات بشكل حتمي |
| **الاختبارات** | **كل حالات EC-1..EC-15**؛ Idempotency؛ عدم رجوع الحالة؛ R/R صحيح |
| **معايير القبول** | كل انتقال مسجّل بسبب+وقت؛ لا انتقال عكسي؛ R/R محسوب لا مُدخل |
| **المخاطر** | حالات حدّية غير مكتشفة — التخفيف: مصفوفة EC إلزامية |

### M3 — محرك السيناريو + بوابة الجودة

| البند | التفصيل |
|---|---|
| **الأهداف** | توليد فرص وتقييمها + قرار النشر |
| **المكونات** | Scenario Generator، Quality Gate، No-Opportunity Log |
| **المهام** | منطق التوليد؛ ربط الأدلة؛ بوابة الجودة؛ تسجيل «لا فرصة»؛ منع التقاطع/التكرار |
| **الاعتماديات** | M2 + **DECISION A** |
| **المخرجات** | سيناريوهات منشورة + سجل «لا فرصة» |
| **الاختبارات** | **إرجاع `NO_VALID_OPPORTUNITY` بنجاح**؛ منع النشر بلا أدلة؛ منع التكرار؛ منع التقاطع |
| **معايير القبول** | لا سيناريو بلا `evidence_ids`+`rationale`؛ «لا فرصة» حالة مُختبَرة لا استثناء |
| **المخاطر** | إفراط/تفريط في النشر — التخفيف: بوابة قابلة للضبط بإصدار قواعد |

### M4 — الرصد الرصدي (Shadow Monitoring)

| البند | التفصيل |
|---|---|
| **الأهداف** | رصد حقيقي للسيناريو بعد النشر |
| **المكونات** | Monitoring loop، Activation detector، TP/SL tracker، Outcome writer |
| **المهام** | كشف التفعيل؛ تتبع TP1/TP2/SL؛ احتساب السبريد/الانزلاق؛ كتابة outcome؛ Data interrupt |
| **الاعتماديات** | M3 + M1 |
| **المخرجات** | نتائج سيناريو Append-only |
| **الاختبارات** | تفعيل صحيح؛ SL/TP بنفس الشمعة (EC-3/EC-4)؛ الفجوات (EC-7/EC-8)؛ انقطاع (EC-5/EC-14)؛ لا Look-ahead |
| **معايير القبول** | outcome لا يُعدَّل بعد الكتابة؛ لا تقييم بشمعة أُغلقت قبل الإنشاء |
| **المخاطر** | انزلاق غير واقعي — التخفيف: احتساب محافظ معلن |

### M5 — السجل والشفافية (Ledger)

| البند | التفصيل |
|---|---|
| **الأهداف** | سجل عام كامل يمنع Survivorship Bias |
| **المكونات** | Ledger queries، Stats، Methodology page |
| **المهام** | إحصاءات منفصلة لكل فئة؛ تعريف المقام؛ الفلترة؛ صفحة المنهجية |
| **الاعتماديات** | M4 + **DECISION C** |
| **المخرجات** | سجل عام + صفحة منهجية |
| **الاختبارات** | المجموع = مجموع الفئات؛ لا نسبة بلا مقام؛ الخاسر ظاهر؛ لا حذف |
| **معايير القبول** | كل نسبة معروضة لها مقام صريح؛ لا سيناريو مخفي |
| **المخاطر** | إحصاءات مضلّلة — التخفيف: اختبار حسابي إلزامي |

### M6 — طبقة AI

| البند | التفصيل |
|---|---|
| **الأهداف** | شرح وتلخيص وإجابة موسومة |
| **المكونات** | Orchestrator، Explainer، Simplifier، Brief Composer، Assistant |
| **المهام** | تجميع السياق؛ Routing؛ Grounding check؛ Cost Ledger؛ مخرجات منظمة |
| **الاعتماديات** | M3/M5 + **DECISION F** |
| **المخرجات** | `ai_explanations` + `daily_briefs` |
| **الاختبارات** | **رفض رقم غير موجود في السياق**؛ رفض المخرجات غير الصحيحة؛ لا كتابة في جداول الحقيقة |
| **معايير القبول** | 100% من المخرجات المعروضة اجتازت Grounding؛ AI لا يكتب في جداول الحقيقة |
| **المخاطر** | اختلاق — التخفيف: Grounding check إلزامي |

### M7 — الواجهة (Ready Trades أولًا)

| البند | التفصيل |
|---|---|
| **الأهداف** | تجربة المستخدم الكاملة بنظام تصميم موحّد |
| **المكونات** | App Shell، Ready Trades، Scenario Detail، Ledger، Brief، Assistant، Education |
| **المهام** | نظام التصميم؛ الشارت؛ بطاقات السيناريو؛ الشرح المزدوج؛ RiskBanner؛ الاستجابة |
| **الاعتماديات** | M2–M6 + **DECISION B** |
| **المخرجات** | تطبيق ويب يعمل |
| **الاختبارات** | RTL؛ التباين AA؛ 11px حد أدنى؛ Mobile؛ حالات البيانات؛ حالات السيناريو |
| **معايير القبول** | لا نص < 11px؛ لا دلالة باللون وحده؛ لا تمرير أفقي؛ كل رقم له مصدر مرئي |
| **المخاطر** | تعقيد بصري — التخفيف: نظام تصميم صارم |

### M8 — الجاهزية التشغيلية

| البند | التفصيل |
|---|---|
| **الأهداف** | أمان، مراقبة، نسخ احتياطي، استعادة |
| **المكونات** | AuthN/AuthZ، Rate limit، Audit، Monitoring، Backup |
| **المهام** | أدوار؛ token للمشغل؛ rate limit؛ Audit log؛ Prometheus/Grafana؛ backup مشفّر؛ اختبار استعادة |
| **الاعتماديات** | M1–M7 |
| **المخرجات** | نظام قابل للتشغيل الآمن |
| **الاختبارات** | منع وصول الزائر للكتابة؛ منع الوصول للمفاتيح؛ اختبار استعادة؛ اختبار rate limit |
| **معايير القبول** | لا سر في bundle المتصفح؛ استعادة مُختبَرة ناجحة |
| **المخاطر** | ثقة زائدة — التخفيف: فحص اختراق أساسي |
