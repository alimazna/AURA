## 1. المفهوم البصري

**«مركز قيادة ذهبي هادئ»** — واجهة مالية داكنة عالية الكثافة، الذهب لمسة هوية لا لون سائد،
والأزرق للتفاعل. الإحساس المستهدف: **دقة، ثبات، شفافية** — لا إثارة ولا زخرفة.

### مراجع الاستلهام (إلهام لا نسخ)

| المرجع | ما نأخذه | ما لا نأخذه |
|---|---|---|
| `aa/AYZR_Reference_Dashboard.png` | الأسطح الداكنة، كثافة المعلومات، تخطيط الشارت+اللوحة | الأرقام التجريبية، البطاقات الزائدة |

**تحذير مُلزِم:** كل الأرقام في الصورة المرجعية **تجريبية**. لا تُنسخ كبيانات سوق.

## 2. القرارات البصرية الحاسمة

| القرار | الاختيار | السبب |
|---|---|---|
| الوضع | داكن فقط في MVP | يقلل إجهاد العين، معياري في المال |
| الذهب | لمسة فقط (هوية، تحذير) | الذهب السائد يبدو غير احترافي |
| الأزرق | التفاعل والبيانات | تباين جيد مع الداكن |
| الزوايا | 4–6px (شبه حادة) | الإحساس بالدقة |
| الظلال | بلا ظلال، حدود فقط | الأنسب لواجهة كثيفة |
| الرسوم المتحركة | شبه معدومة | الأداء والهدوء |

## 3. التسلسل الهرمي البصري (Ready Trades)

```
المستوى 1: حالة البيانات + السعر (الشريط العلوي)     ← ثقة فورية
المستوى 2: الشارت (البطل البصري، أكبر عنصر)
المستوى 3: لوحة السيناريو النشط (الحالة + المستويات)
المستوى 4: زر «لماذا؟» (المدخل للفهم)
المستوى 5: قائمة السيناريوهات الأخرى
المستوى 6: الأدلة والتفاصيل (عند التوسيع)
```

**قاعدة:** لا شيء فوق الشارت إلا ما يحتاجه المستخدم ليثق بالبيانات.

## 4. تمييز المؤكد عن المُفسَّر (بصريًا)

| النوع | العلاج البصري |
|---|---|
| رقم موثق | نص أبيض/رمادي، مع توقيت ومصدر عند المرور |
| تفسير AI | إطار ذهبي متقطع + وسم «تفسير مُولَّد» |
| بيانات قديمة | شريط أصفر + عمر التحديث |
| لا فرصة | بطاقة رمادية هادئة + «لا توجد فرصة صالحة» |
| درجة | «ترتيب داخلي — ليس احتمالًا» أسفلها دائمًا |

## 5. نموذج التخطيط (Desktop ≥1440px)

```
┌──────────────────────────────────────────────────────────────────┐
│ 64px  الشريط العلوي                                              │
├──────────┬───────────────────────────────────────────────────────┤
│ 200px    │                                                       │
│ القائمة  │   الشارت (يمتد)          │  لوحة السيناريو 360px     │
│ الجانبية │                          │                           │
│          │                          │                           │
│          ├──────────────────────────┴───────────────────────────┤
│          │  شريط السيناريوهات الأفقية (ارتفاع 96px)             │
└──────────┴──────────────────────────────────────────────────────┘
```

- **الشريط العلوي:** 64px.
- **القائمة الجانبية:** 200px (تنهار إلى أيقونات 64px في اللوحي، وتصبح Drawer في الهاتف).
- **لوحة السيناريو:** 360px ثابتة على Desktop، وتصبح بطاقة أسفل الشارت في الهاتف.
- **البطاقات السفلية:** تُمرَّر أفقيًا.

## 6. تفاصيل الشارت

| العنصر | المواصفة |
|---|---|
| النوع | Candlestick (شموع) |
| الألوان | أخضر/أحمر مخصصان منفصلان عن `--up`/`--down` الدلاليين |
| الشبكة | خافتة جدًا (`--line`) |
| الطبقات | منطقة الدخول (شفاف أزرق)، SL (أحمر متقطع)، TP1/TP2 (أخضر متقطع)، مناطق السيولة (بني شفاف) |
| التفاعل | ضغط على أي عنصر → تفاصيله (مصدر، توقيت، حالة) |
| الأطر | M1 M5 M15 H1 H4 D1 (تبويبات) |
| مؤشر عمر البيانات | أعلى اليسار، دائم الظهور |
| السعر الأخير | Badge يمين المحور، مع منع التصادم مع التيكات |

**قاعدة منع التصادم:** لا يقترب أي رقمان أقل من 14px رأسيًا (منع قراءة رقم مشوّه).

## 7. الحالات الفارغة (Empty States)

| الحالة | النص | التصميم |
|---|---|---|
| لا فرص | «لا توجد فرصة صالحة حاليًا. هذا طبيعي — الجودة تحكم النشر.» | بطاقة هادئة + سياق السوق |
| بيانات غير متاحة | «البيانات غير متاحة حاليًا. لا نعرض أرقامًا غير موثوقة.» | إطار رمادي، لا شارت |
| لا سجل | «لم تتابع أي سيناريو بعد.» | بطاقة تعليمية + زر «تصفح الفرص» |
| خطأ | «تعذّر التحميل. حاول مرة أخرى.» | زر إعادة المحاولة |

## 8. نبرة الكتابة العربية (Tone of Voice)

| المبدأ | مثال جيد | مثال مرفوض |
|---|---|---|
| صادق | «لم تُفعَّل بعد» | «فرصة مؤكدة» |
| واضح | «وقف الخسارة: السعر الذي تُغلق عنده» | «SL 4031.50» بلا شرح |
| لا مبالغة | «سيناريو مقترح» | «صفقة ذهبية مضمونة» |
| لا وعد | «قد لا يتحقق» | «نسبة نجاح 90%» |
| محايد | «تحقق الهدف» | «ربحنا!» |

## 9. ممنوعات التصميم (Hard NO)

1. أي زر يوحي بتنفيذ تداول حقيقي.
2. عرض احتمالية أو نسبة دقة متوقعة.
3. أرقام بلا مصدر أو توقيت.
4. إخفاء أي سيناريو خاسر.
5. رسوم متحركة مستمرة أو زخرفية.
6. نص عربي أصغر من 11px.
7. الاعتماد على اللون وحده للدلالة.
8. نسخ أي رقم من الصورة المرجعية كبيانات سوق.
