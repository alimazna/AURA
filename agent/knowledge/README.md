# قاعدة المعرفة — AYZR AURIX

هذه ليست مستندات. هذه **قاعدة معرفة تُشغَّل**: ملف قواعد يقرأه البرنامج، ودفتر
أدلة يتراكم، وحلقة تعيد القياس على بيانات جديدة.

## الملفات

| الملف | الدور |
|---|---|
| `rules.json` | ما أعرفه — كل قاعدة مع دليلها وحالتها وطريقة استخدامها |
| `evidence.jsonl` | دفتر القياسات — **يُضاف فقط، لا يُحذف**. قياس يخالف قياساً سابقاً هو أثمن سطر فيه |
| `learn_history.jsonl` | سجل دورات التعلّم |

## حالات القاعدة

| الحالة | المعنى | تُستخدم في القرار؟ |
|---|---|---|
| `proven` | قيست وسبقت التعادل والخط الأساسي بفرق واضح | نعم — بوّابة أو شرط |
| `direction` | الاتجاه واضح، الدلالة لم تثبت (p ≥ 0.05) | نعم — كشرط، مع تحفّظ |
| `unproven` | لم يثبت شيء | لا — وصف فقط |
| `refuted` | دحضها القياس | **ممنوع** — تبقى للتذكير لا للطاعة |

## كيف تُستخدم فعلاً

```bash
# تحليل السوق الآن بقاعدة المعرفة (يطبّق القواعد ويخرج قراراً)
python3 agent/tools/kb.py --tf 15m

# مخرجات للبرامج
python3 agent/tools/kb.py --tf 1h --json

# دليل قاعدة واحدة
python3 agent/tools/kb.py --why R-STOP-MIN

# حلقة التعلّم: أعد القياس وحدّث القاعدة
python3 agent/tools/learn.py --tf 1d
python3 agent/tools/learn.py --tf 1d --dry-run   # بلا كتابة
```

## ما تفعله القاعدة في القرار

القاعدة **لا** تخترع صفقات. تستطيع فقط:

- **ترفض** دخولاً (بوّابة مُثبتة اشتعلت)،
- **تشترط** شرطاً (ارتداد إلى EMA20)،
- **تضبط** معامل خطر (أرضية الوقف 0.5×ATR، الأهداف 1R/1.5R)،
- **تصف** حالة (بلا قرار)،
- **تمنع ادّعاء** ربحية.

## الضوابط المفروضة في الكود

هذه ليست نصائح — الكود يفرضها:

1. **صفقة واحدة في كل مرة** — العدّ المتراكب يضخّم 6.5 نقطة.
2. **خط أساس عشوائي** مطبوع مع كل قياس.
3. **عينة ≥ 94 صفقة أو p < 0.05** قبل ترقية أي حالة.
4. **التحقق خارج العينة** إلزامي.
5. **المقارنة بالـR** عند اختلاف الأوقاف/الأهداف.
6. **كل عتبة مقيَّسة بـATR** لا عشوائية.
7. **الإعادة مفصولة عن الدفتر الحيّ**.
8. **حل متشائم**: شمعة تلمس الوقف والهدف = خسارة.
9. **لا نظر مستقبلي**: صفقة على إغلاق T تُحكم بعد T فقط.

## الحقيقة الحالية (مهمة)

- **لا ادّعاء ربحية.** `R-PROFITABILITY` حالتها `unproven`.
- **أفضل ما عندي** — «ارتداد» 47.5% مقابل تعادل 43.5% — لكن n=40 < 94.
- **R-TREND-CONFLICT** تُثبت أن التعارض سيئ (25% مقابل 41.4%)، لكن حالة
  الاتفاق نفسها **تحت التعادل**. القاعدة صحيحة نسبياً ولا تكفي للربح. الحلقة
  تطبع هذا صراحةً، لا تُخفيه.
- **لم آخذ صفقة حيّة رابحة بعد.** لا صفقات حية مُغلقة أصلاً.
